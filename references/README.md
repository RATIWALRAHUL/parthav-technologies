## Visual Source of Truth Guidelines

When implementing or refining sections:

1. **Treat the reference screenshot as the primary visual authority.**
2. **Compare Spacing**: Match vertical gaps, container gutters, and padding.
3. **Compare Proportions**: Ensure card widths, image aspect ratios, and column splits align with the reference.
4. **Compare Typography**: Verify headline scale, line-height, letter-spacing, and eyebrow treatments.
5. **Compare Layout**: Check the precise sequence and alignment of UI elements.
6. **Compare Image Treatment**: Maintain high-end editorial workspace photography and subtle framing.
7. **Compare Section Hierarchy**: Respect the alternation of clean white and deep navy sections.

> **RULE**: Do not blindly redesign sections based on subjective preference. Preserve what is already verified and refine only elements that diverge from the reference.
